# Content samples

Fictional, author-written examples (licence CC0-1.0) for
[docs/CONTENT_AUTHORING.md](../../../docs/CONTENT_AUTHORING.md). `ferry_keeper.md` is an
NPC source, `larkford.md` a world source and `review.csv` the reviewed sheet for both:
an approved `static` bio, NPC facts and global facts, a fact that conflicts with the
`scripts/seed_example.php` row for `npc_guide` (the importer keeps the existing row), a
row classified `spoiler` and rejected because it depends on player progress, and a pending
row whose availability is not decided yet.
